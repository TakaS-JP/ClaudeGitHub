# 茨城県更生保護協会 基本財産運用検討会 提出資料

2026年9月14日改訂：理事会を2027年1月予定として全資料のスケジュールを修正。基本財産資料には検討会資料（令和8年7月23日、Box「(更生保護協会)」フォルダ）の6月30日現在の財産目録別紙・国債購入仮計算・投資信託評価額を反映。出典資料はBox「ScanSnap」から「0.鈴木孝昌／(更生保護協会)」へ移動済み。

- `基本財産運用検討会_提出資料案_2026-09.docx` : 提出資料（正本、Word）
- `基本財産運用検討会_提出資料案_2026-09.md` : 同内容のMarkdown版（閲覧用に自動変換）
- `build/make.js` : Word文書の生成スクリプト（`npm install docx@8` 後に `node make.js 出力先.docx`）
