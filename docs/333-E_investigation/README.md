# 333-E地区 ライオンズクエスト交付金事案 調査関連文書

## 1. 本件の概要

2026年5月開催のLCIF交付金支給に関する会議において、複層地区333-E地区（以下「当該地区」）のライオンズクエスト（以下「LQ」）に関わるLCIF交付金申請内容に疑義が提起された。具体的には以下の点である。

- 当該地区では、毎年特定の固定したクラブのみがLQワークショップを実施しており、地区全体への展開が乏しい。
- LQワークショップにおいて、本来の対象者（学校教員等）の参加が十分に集まらないため、対象外と思われる **幼稚園教諭** 等を参加者に組み入れて開催を成立させている事例があるとの情報が寄せられている。
- LCIF交付金は申請書記載の計画（対象者、参加者数、目的、実施内容）に基づいて支給されており、申請内容と実施内容に重大な乖離がある場合、虚偽申請に該当し、交付金の返還を要する可能性がある。

LCIF理事会に対して明確な回答を行うため、本調査を実施する。
