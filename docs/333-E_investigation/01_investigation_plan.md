## 1. 調査の目的

複層地区333-E地区において実施されたライオンズクエスト（以下「LQ」）ワークショップに関して、LCIF交付金申請書記載の計画と実際の実施内容との間に乖離があるか否か、また虚偽申請に該当する事実があるか否かを、客観的な資料・証拠に基づいて確認する。その結果を整理し、LCIF理事会への報告を行うことを目的とする。

## 2. 調査の前提となる疑義（仮説）

本調査は、以下の情報提供を出発点とする。これらは現時点で **未検証の主張** であり、調査により事実関係を確認する。

1. 当該地区では毎年同一の限定されたクラブのみがLQワークショップを実施しており、地区全体への展開が不十分である。
2. ワークショップの本来の対象者である学校教員等の参加申込みが不足した際に、対象外と思われる **幼稚園教諭** 等を参加させて開催を成立させた事例がある。
3. 上記が事実である場合、LCIF交付金申請書に記載された対象者・参加者数・実施内容との間に乖離が生じている可能性がある。

## 3. 調査範囲

### 3.1 対象期間

直近3年度分のLCIF交付金申請に対応するワークショップ実施分とする。
（年度・回次は地区LQ委員会の記録に基づき特定する。）

### 3.2 対象事項

| # | 確認事項 |
|---|----------|
| 1 | 各年度のLCIF交付金申請書（写）の入手と内容確認 |
| 2 | 申請書記載の **対象者区分**（小学校教員／中学校教員／高校教員／その他）と **計画参加者数** |
| 3 | 実施報告書および参加者名簿の内容と、申請書との突合 |
| 4 | 参加者の所属（学校種・学校名・職位）と本人確認の根拠資料 |
| 5 | 主催クラブの選定経緯と、地区全体への参加機会の周知状況 |
| 6 | 交付金の使途（講師謝礼、会場費、教材費、その他）と領収書等の保管状況 |
| 7 | 過去3年度における実施クラブの一覧と、その重複・偏在の状況 |
| 8 | 地区LQ委員会の運営体制、議事録、意思決定プロセス |

### 3.3 調査対象外

- 個別会員の人物評価・人格的批判
- 交付金事案と直接関係のないクラブ運営事項
- 法的責任の最終判断（必要に応じ別途、法務専門家の助言を仰ぐ）

## 4. 調査方法

### 4.1 書面調査

- 地区ガバナー及び地区LQ委員長宛に **資料提出依頼書（質問状）** を発出（別紙 `02_inquiry_letter.md` 参照）。
- LCIF日本担当事務局を通じて、申請書原本（写）を入手。
- ライオンズクエスト・ジャパンに対して、当該ワークショップに関する公式記録（受講者名簿、開催実績）を照会。

### 4.2 ヒアリング

| 対象 | 主な確認内容 |
|------|--------------|
| 当該地区ガバナー（現・前） | 地区方針、クラブ間の参加機会均等化の取組み |
| 地区LQ委員長（現・前）     | ワークショップ企画・募集・運営の実態 |
| 主催クラブ会長／担当者     | 募集経緯、参加者構成、申請書記載との整合性 |
| 認定トレーナー             | 実際の受講者層、研修内容、教材使用状況 |
| （必要に応じ）参加者数名    | 参加経緯、所属、研修内容の受講事実 |

### 4.3 突合分析

- LCIF交付金申請書（計画値）× 実施報告書（実績値）× 参加者名簿（個別根拠）の **3者突合**。
- 乖離が認められる項目について、その規模・性質・反復性を評価。

## 5. 事実認定の基準

各事項について以下のいずれに該当するかを記述する。

- **A. 申請内容に整合**
- **B. 軽微な相違**（運営上の合理的範囲内、計画値と実績の通常変動）
- **C. 重大な相違**（対象者区分の不一致、参加者数の大幅な乖離、目的逸脱）
- **D. 虚偽申請の疑い**（書面と実態が客観的に異なり、かつ申請者がそれを認識し得たもの）

C・Dに該当する事項については、根拠資料を明記する。

## 6. 留意事項

- 関係者には推定無罪の原則に立つ。
- 情報提供者の保護（匿名性確保）に十分配慮する。
- 調査委員と被調査者の利害関係（同一クラブ所属等）を確認し、必要に応じ除斥する。
- 記録は調査委員会で一元管理し、外部漏洩を防止する。
- 本人弁明の機会を必ず付与する。
