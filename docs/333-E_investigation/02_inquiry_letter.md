## 1. 趣旨

2026年5月開催の交付金支給に関する会議において、貴地区におけるライオンズクエスト（以下「LQ」）ワークショップに関するLCIF交付金申請内容に疑義が提起されました。当委員会はこれを受け、客観的事実の確認を行っております。

つきましては、下記資料のご提出と質問へのご回答をお願い申し上げます。本依頼は調査の一環であり、現時点で何らかの結論を示すものではありません。貴地区の説明責任を果たしていただくための機会としてご協力をお願いいたします。

## 2. 提出をお願いする資料

### 2.1 LCIF交付金関連

直近3年度分について、以下をご提出ください。

1. LCIF交付金申請書（写）
2. LCIFからの採択通知（写）
3. LCIFへの実施報告書（写）
4. 交付金受領を裏付ける会計記録（入出金記録、領収書綴り）

### 2.2 ワークショップ実施記録

各回について以下をご提出ください。

5. 開催要項・募集チラシ・案内文書
6. 申込書一式（個人情報は適宜マスキング可）
7. **参加者名簿**（氏名・所属機関・職位・参加日が確認できるもの）
8. 受講証・修了証の交付記録
9. 当日の配布資料・プログラム・写真記録（撮影されている場合）
10. 講師（認定トレーナー）との契約書・謝礼支払記録

### 2.3 地区運営記録

11. 過去3年度における **地区LQ委員会議事録**
12. ワークショップ開催に関する **クラブ向け案内文書**（全クラブへの周知の有無を確認するため）
13. 過去3年度の **実施クラブ一覧**

## 3. ご回答をお願いする質問事項

| # | 質問 |
|---|------|
| Q1 | 貴地区において、LCIF交付金申請書に記載した「対象者区分」（小学校・中学校・高等学校教員等）は、各年度において具体的にどのように規定されていましたか。 |
| Q2 | 申請書記載の対象者以外（例：幼稚園教諭、保育士、その他）を参加させた事例はありましたか。あった場合、その人数、年度、判断理由をご教示ください。 |
| Q3 | 上記Q2の事例について、ライオンズクエスト・ジャパン事務局及びLCIFに対し、事前または事後に報告・相談を行いましたか。行った場合、その記録をご提出ください。 |
| Q4 | 過去3年度において、ワークショップを実施したクラブはどこですか。重複がある場合、それは偶然か、あるいは地区方針によるものですか。 |
| Q5 | 貴地区内の **未実施クラブ** に対し、参加機会の周知・働きかけはどのように行いましたか。記録があればご提出ください。 |
| Q6 | 申請書記載の **計画参加者数** と実際の参加者数の間に乖離があった年度・回次はありますか。あった場合、その経緯と対応をご説明ください。 |
| Q7 | 受講者の所属（学校名・職位）は、誰が、どの資料に基づいて確認していましたか。確認手続きをご説明ください。 |
| Q8 | LCIFへの実施報告書を作成する際、参加者の所属区分は誰がどのように確認・集計しましたか。 |
| Q9 | 本件に関し、貴地区として既に把握している課題・改善点があればご教示ください。 |

## 4. 提出期限

**2026年6月◯日（提出後14日以内）** を目安にご提出ください。やむを得ない事情で期限内の提出が困難な場合は、事前にご連絡ください。

- 紙資料：複合地区事務局宛に書留郵送。
