# 特定技能外国人 受入時 必要書類一覧

特定技能（1号）の外国人材を受け入れる際に必要となる書類を、以下2つのパターンに分けて整理しています。

- **パターンA：新規受入**（海外から呼び寄せ／他在留資格からの新規申請）
- **パターンB：技能実習からの在留資格変更**（技能実習2号・3号良好修了者）

> 出典：出入国在留管理庁「特定技能運用要領」および各種申請様式（最新版を必ず公式サイトでご確認ください）。

---

## 1. 申請区分の確認

| 区分 | 提出する申請 | 主な対象者 |
|------|--------------|------------|
| パターンA：新規受入 | **在留資格認定証明書交付申請**（海外在住者）<br>または **在留資格変更許可申請**（留学・家族滞在等から） | 海外から新たに呼び寄せる者／留学生・他在留資格者 |
| パターンB：技能実習からの変更 | **在留資格変更許可申請** | 技能実習2号良好修了者・3号修了者 |

---

## 2. 共通して必要な書類

新規受入・技能実習からの変更ともに、以下は基本的に必要です。

### 2-1. 申請人（外国人本人）に関する書類

| No. | 書類名 | 備考 |
|-----|--------|------|
| 1 | 在留資格認定証明書交付申請書／在留資格変更許可申請書 | 法務省指定様式 |
| 2 | 顔写真（縦4cm×横3cm） | 3か月以内撮影 |
| 3 | パスポートおよび在留カードの写し | 在留中の場合 |
| 4 | 特定技能外国人の報酬に関する説明書（参考様式第1-4号） | |
| 5 | 雇用条件書（参考様式第1-6号） | 日本人と同等以上の報酬であること |
| 6 | 雇用契約書の写し | 双方署名済み |
| 7 | 事前ガイダンスの確認書（参考様式第1-7号） | 母国語で実施 |
| 8 | 健康診断個人票（参考様式第1-3号） | 1年以内のもの |
| 9 | 1号特定技能外国人支援計画書（参考様式第1-17号） | 10項目の支援内容 |
| 10 | 支援委託契約書の写し | 登録支援機関に委託する場合 |

### 2-2. 受入機関（所属機関）に関する書類

| No. | 書類名 | 備考 |
|-----|--------|------|
| 1 | 特定技能所属機関概要書（参考様式第1-11号） | |
| 2 | 登記事項証明書 | 3か月以内 |
| 3 | 業務執行に関与する役員の住民票の写し | マイナンバー記載なし |
| 4 | 労働保険料等納付証明書（その2） | 直近2年分 |
| 5 | 社会保険料納入状況回答票または納入証明書 | |
| 6 | 税務署発行の納税証明書（その3） | 法人税・消費税等 |
| 7 | 法定調書合計表の写し | 直近年度 |
| 8 | 決算文書の写し | 直近2年度分 |
| 9 | 特定技能雇用契約に係る誓約書（参考様式第1-9号） | |
| 10 | 1号特定技能外国人支援計画の概要書（参考様式第1-18号） | |

### 2-3. 分野別の追加書類（共通）

業種ごとに所管省庁が定める協議会への加入証明等が必要：

- **介護**：介護分野における特定技能協議会 加入証明
- **建設**：建設特定技能受入計画認定証（国交省）、JAC加入証明
- **農業／漁業／飲食料品製造業／外食業／宿泊／自動車整備／航空／造船・舶用工業／素形材・産業機械・電気電子情報関連製造業 等**：各分野所管省庁の協議会加入証明書

## 3. パターンA：新規受入の場合の追加書類

海外から呼び寄せる、または日本国内の他在留資格から新たに特定技能へ移行する場合に**追加で**必要となる書類です。

### 3-1. 技能水準の証明

| No. | 書類名 | 備考 |
|-----|--------|------|
| A-1 | **特定技能評価試験 合格証明書** | 分野別技能試験（例：介護技能評価試験、製造分野特定技能1号評価試験 など） |
| A-2 | **日本語能力の証明書** | 以下のいずれか<br>・日本語能力試験（JLPT）N4以上<br>・国際交流基金日本語基礎テスト（JFT-Basic）合格<br>・介護分野は追加で介護日本語評価試験合格 |

### 3-2. その他

| No. | 書類名 | 備考 |
|-----|--------|------|
| A-3 | 申請人の履歴書（参考様式第1-1号） | |
| A-4 | 海外の親族関係書類 | 必要に応じて |
| A-5 | 二国間取決め（MOC）に基づく証明書 | 送り出し国による（ベトナム・フィリピン・カンボジア・ミャンマー・ネパール等） |
| A-6 | 送り出し機関との契約書写し | 該当国のみ |
| A-7 | 徴収費用に関する説明書（参考様式第1-5号） | 渡航費・仲介手数料等の負担を明示 |

> **ポイント**：新規受入は「技能試験＋日本語試験」の合格が**必須**です。試験合格証は原本の写しを提出します。

---

## 4. パターンB：技能実習からの在留資格変更の場合の追加書類

技能実習2号を**良好に修了**した者（または3号修了者）は、関連分野であれば**試験免除**で特定技能1号へ移行可能です。

### 4-1. 技能実習修了の証明

| No. | 書類名 | 備考 |
|-----|--------|------|
| B-1 | **技能検定3級または同等以上の評価調書（合格証書の写し）** | 技能実習2号修了の証明 |
| B-2 | **技能実習生に関する評価調書（参考様式第1-2号）** | 前監理団体・実習実施者発行<br>「出勤状況」「技能修得状況」「生活態度」が良好であることの記載 |
| B-3 | 技能実習中の在留カードの写し | 全ページ |
| B-4 | 技能実習計画の写し | 必要に応じて |

> **B-2が取得できない場合の代替**：
> 前職の評価調書が入手困難な場合は、以下のいずれかで代替可能。
> - 技能実習生総合保険等の保険加入証明
> - 給与振込実績がわかる通帳の写し（直近1年）
> - 技能検定3級等の合格証書の写し
> + **理由書**（参考様式第1-23号）に取得困難な事情を記載

### 4-2. 試験免除の確認

| 移行元（技能実習2号の職種） | 移行先（特定技能1号の分野） | 試験免除 |
|------------------------------|------------------------------|:---------:|
| 介護 | 介護 | ○ |
| 建設関係（とび・型枠施工 等） | 建設 | ○ |
| 農業（耕種・畜産） | 農業 | ○ |
| 漁業 | 漁業 | ○ |
| 食品製造関係 | 飲食料品製造業 | ○ |
| ※関連性のない職種への移行は試験合格が必要 | | × |

### 4-3. その他（パターンB特有）

| No. | 書類名 | 備考 |
|-----|--------|------|
| B-5 | 退職証明書（前実習実施者発行） | |
| B-6 | 源泉徴収票（前職分） | |
| B-7 | 住民税の課税・納税証明書 | 直近1年分 |
| B-8 | 年金記録（ねんきん定期便等の写し） | |

> **ポイント**：パターンBでは**日本語試験・技能試験の受験は原則不要**です。代わりに「技能実習を良好に修了したこと」の客観的証明が中心となります。

## 5. 比較サマリー（早見表）

| 項目 | パターンA：新規受入 | パターンB：技能実習からの変更 |
|------|:-------------------:|:-----------------------------:|
| 申請の種類 | 認定証明書交付申請<br>または変更許可申請 | 在留資格変更許可申請 |
| 技能試験の合格証 | **必要** | 不要（評価調書で代替） |
| 日本語試験の合格証 | **必要**（JLPT N4 / JFT-Basic 等） | 不要 |
| 技能実習評価調書 | 不要 | **必要**（参考様式第1-2号） |
| 二国間取決め関連書類 | 該当国は必要 | 不要（在留中のため） |
| 健康診断書 | 必要 | 必要 |
| 事前ガイダンス | 必要 | 必要 |
| 支援計画書 | 必要 | 必要 |
| 標準的な審査期間 | 1〜3か月（在外公館手続含む） | 約1〜2か月 |

---

## 6. 申請の流れ（参考）

### パターンA：新規受入（海外から）
1. 雇用契約締結 → 支援計画策定
2. 受入機関が地方出入国在留管理局へ**在留資格認定証明書**を申請
3. 認定証明書を本人へ送付 → 在外公館でビザ申請
4. 入国 → 在留カード交付 → 就労開始

### パターンB：技能実習からの変更
1. 技能実習2号修了見込み（修了の3〜6か月前から準備開始）
2. 雇用契約締結 → 支援計画策定
3. 地方出入国在留管理局へ**在留資格変更許可申請**
4. 許可 → 新在留カード交付 → 特定技能として就労開始

> **注意**：技能実習の在留期限が切れる前に申請すること。期限後は「特定活動（4か月）」への移行で審査期間を確保することも可能。

---

## 7. 提出先・問合せ先

- **申請書類提出先**：地方出入国在留管理局（住所地または受入機関所在地を管轄）
- **分野別の協議会**：各所管省庁ウェブサイト
- **参考様式ダウンロード**：[出入国在留管理庁 公式サイト](https://www.moj.go.jp/isa/)
