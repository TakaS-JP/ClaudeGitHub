# 監理責任者変更届　提出資料一式

技能実習法に基づく監理団体の **監理責任者変更届** およびその添付書類のテンプレートです。
外国人技能実習機構（OTIT）への提出を想定しています。

## 提出時期

監理責任者を変更したときは、変更後 **1か月以内** に外国人技能実習機構の地方事務所・支所の認定課へ届出が必要です（技能実習法第32条第3項、施行規則第17条）。

## 法令上の根拠

- 外国人の技能実習の適正な実施及び技能実習生の保護に関する法律（技能実習法）第32条
- 同法施行規則 第17条、第52条
- 主務省令で定める「監理事業に関する管理簿」の記載事項

## 監理責任者の要件（チェックポイント）

監理責任者は次の要件をすべて満たす必要があります。

- [ ] 監理団体の常勤の役員または職員であること
- [ ] 過去5年以内に「監理責任者等講習」を修了していること
- [ ] 技能実習法第10条各号の **欠格事由に該当しない** こと
- [ ] 自己が監理する実習実施者の役職員でないこと（独立性）
- [ ] 監理事業を行う事業所ごとに選任されていること

## 提出方法

外国人技能実習機構　地方事務所・支所　認定課　あて
- 持参または郵送（特定記録郵便等、配達記録の残る方法を推奨）
- 副本を1部控えとして保管すること
